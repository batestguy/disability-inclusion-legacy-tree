# Final UI fixes — 6 November 2026

The owner reported missing desktop language buttons and poor mobile network
connections, then approved a horizontal mobile graph. This checkpoint completes
those fixes and saves the preceding site polish after commit 55a6a61.

## Desktop language controls

The former relative header scrolled out of view while users explored records.
Inactive language choices also blended into the white header. The desktop header
now stays visible, with all four language buttons filled green and stacked in the
accepted English / Hausa / Yorùbá / Igbo order. Explicit desktop/tablet grid rules
keep the controls inside the viewport. Header measurement supplies scroll padding
so chart selections, keyboard focus and source headings are not covered.

## Mobile graph

The previous mobile CSS hid the map and its Network/List controls and forced a
list. The SVG paths also had no arrowheads. Network now remains a readable
horizontal Isa → people/organisations → initiatives layout on a scrollable canvas.
The scroll panel supports native touch/keyboard scrolling without widening the
page. It centres on Isa initially and after layout, locale, filter or view changes.
SVG arrowheads follow all existing edges; solid, dashed and dotted relationship
styles, selection highlighting, exact source roles and record links are retained.
List remains an explicit alternative. Scroll hints have all four draft locales.
