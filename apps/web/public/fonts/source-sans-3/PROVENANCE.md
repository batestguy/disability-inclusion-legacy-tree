# Source Sans 3

Unmodified Adobe Source Sans 3 WOFF2 OTF fonts, self-hosted for dashboard UI.
Source repository: https://github.com/adobe-fonts/source-sans
Revision: 87b37a2daaed80fcb8e8ccb0085c4d72ddade12e (release branch, fetched 27 October 2026).

- regular.woff2: WOFF2/OTF/SourceSans3-Regular.otf.woff2
- semibold.woff2: WOFF2/OTF/SourceSans3-Semibold.otf.woff2
- LICENSE.md: original SIL Open Font License 1.1; retained alongside fonts.

No external font requests or production package dependency. These are original
font files, without subsetting, renaming or other modification.
